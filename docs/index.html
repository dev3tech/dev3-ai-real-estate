DEV3 AI Real Estate Listings for WordPress

Property listings for sale and rent, agents and agencies, map search, saved-search alerts, favourites, compare, a lead inbox, a mortgage calculator and RealEstateListing schema — plus optional DEV3 AI that writes descriptions from your photos.

Install

  1. In WordPress go to Plugins → Add New → Upload Plugin and upload dev3-ai-real-estate.zip.
  2. Activate it. A menu DEV3 AI Real Estate appears in wp-admin.

Requirements: WordPress 6.0+, PHP 7.4+ (tested on 8.3). Works with block themes (e.g. Twenty Twenty-Five) and classic themes (e.g. Twenty Twenty-One).

First setup

  1. Settings → Pages → Create missing pages creates Property Search, Submit Property, Agent Dashboard, Saved Properties and Compare Properties, each with its block.
  2. Settings → Prices and units: currency code and symbol, separators, m² or ft².
  3. Settings → Maps: OpenStreetMap works without a key; for Google Maps paste a browser key (Maps JavaScript + Geocoding APIs) and set the default map centre.
  4. Agents: add agents and link each to a WordPress user. Linked users get the Real estate agent role and can use the front-end submission form and dashboard.
  5. Properties → Add property: add photos, details, location and publish.
Property types, locations and features are managed in Settings → Vocabulary. A city typed on a property automatically becomes a location for search.

Gemini API key

  1. Open Google AI Studio, sign in and click Create API key.
  2. In wp-admin open DEV3 AI Real Estate → API Config, paste the key and click Save. It is stored encrypted and never sent to the browser. You can also define DEV3RE_GEMINI_API_KEY in wp-config.php.
  3. Choose models (default gemini-2.5-flash), set a monthly budget, and decide if visitor-facing AI (plain-language search) is on.

Properties

Each property has: sale/rent with rent period, price (or "price on request"), prefix/suffix, beds, baths (halves allowed), parking, living area in m² or ft², lot size, year built, floor, energy class, reference, address with map pin and an option to hide the exact address, photo gallery, floor plans (image, beds, baths, area, notes), virtual tour link, video link, highlights, features, neighbourhood text and the agent. Availability can be Available, Under offer, Sold or Rented; sold and rented listings stay online with a label and are hidden from search (setting).

The single page shows the gallery (swipe on phones, lightbox with keyboard support), key facts, highlights, details, features, floor plans, a click-to-load virtual tour, the map with nearby places, the neighbourhood section, the mortgage calculator, the agent card with an enquiry/viewing form and similar properties.

Allowed tour hosts: Matterport, Kuula, CloudPano, Giraffe360, Momento360, Roundme, Theasys, YouTube, Vimeo and Google Maps embeds (filter dev3re_tour_hosts).

Agents & agencies

Agents have a photo, job title, contact numbers, WhatsApp, email, licence, languages, website and social links, an agency and an optional linked user. Agent and agency pages list their active properties and include a contact form. Leads for a property go to its agent (or to the site notification email when there is no agent).

Front-end submission

The Submit Property page lets agents upload photos (JPEG, PNG, WebP up to 10 MB, drag or arrows to reorder), fill in details, drop a map pin, add floor plans and a tour, and ask DEV3 AI for a description. New listings wait for review or go live right away (Settings → Front-end submission). The Agent Dashboard lists the agent's properties with views and leads, lets them change availability, edit or delete, answer leads and edit their profile. Turn on Let logged-in users become agents themselves to allow self sign-up.

Search & map

The search page combines a plain-language box, buy/rent toggle, type, location, price, bedrooms and More filters (bathrooms, area, year built, keyword, features). Results update without reloading, the URL is shareable and the back button works. On wide screens a sticky map shows price tags; on phones a Map button switches views. Tick Search as I move the map to search the visible area.

Saved searches & alerts

Visitors click Save search and pick daily, weekly or "as soon as listed". Guests confirm by email (double opt-in). An hourly cron sends a digest of properties added since the last email; every email has a one-click unsubscribe link. Admins see all saved searches under Saved searches and can send alerts on demand.

Favourites & compare

The heart button saves a property (in the browser for guests, in the account for logged-in users; browser favourites are merged after login). The compare button adds up to 4 properties to a sticky compare bar and the Compare Properties page shows a side-by-side table including price per area and features.

Enquiries & leads

Enquiry and viewing requests are stored in the lead inbox, emailed to the agent (reply-to the visitor), copied to the admin (setting) and confirmed to the visitor with an auto-reply (setting). Forms have a consent checkbox, a honeypot and per-IP rate limits. In Leads you can filter by status and agent, add private notes, reply and export CSV.

Mortgage calculator

Shown on every property for sale (pre-filled with its price) and available as a block. Defaults for rate, term and down payment are in Settings. Monthly payment uses the standard annuity formula; the bar shows principal versus interest.

Schema

Property pages output RealEstateListing JSON-LD with the offer (price, currency, sale or lease, availability, agent), and the residence (address, geo, bedrooms, bathrooms, floor size, year built, amenities). Agent and agency pages output RealEstateAgent. Hidden addresses omit the street and coordinates. Filter: dev3re_schema.

DEV3 AI · Description from photos

In the property editor (and the agent submission form), add photos and optional private notes, then click Write from photos with DEV3 AI. DEV3 AI looks at up to 8 photos plus the facts and writes a title, a card summary, a 3–5 paragraph description and highlights, and suggests features from your own feature list. You see a word-level diff against the current text and can edit, accept or reject. Nothing is saved until you accept and save. Start from the facts (no AI) creates a template draft without AI.

DEV3 AI · Neighbourhood highlights

From the address or map pin the plugin asks OpenStreetMap (Overpass API) for schools, public transport, parks, shops, healthcare, restaurants and gyms within about 1 km (cached for 30 days). DEV3 AI writes a short factual summary and highlights based only on those places. AI text is labelled on the listing ("AI-generated summary") until you switch the label off after checking it. List nearby places (no AI) produces a plain list without AI.

DEV3 AI · Plain-language search

Visitors can type requests like "4 bed house for sale under 1.5m with a pool". DEV3 AI turns the text into filters that must match your own types, locations and features; the result is cached for a day. When AI is off, the storefront AI switch is off, the budget is reached or the rate limit applies, the built-in parser handles numbers, prices ("500k", "1.2m", "between 200k and 350k"), beds, baths, areas, types, features and locations.

Budget & privacy

  • API Config: monthly budget cap, AI on/off, storefront AI switch, caching and PII masking.
  • Usage Logs: requests, tokens and estimated cost per feature.
  • Data sent to Google Gemini: photos, facts and notes (descriptions), the address and nearby place names (neighbourhood), the visitor's search text (search). Lead contact details are never sent.
  • The privacy policy helper and the WordPress personal-data exporter/eraser cover leads and saved searches.

FAQ

Does it work without AI?

Yes, every feature. AI only adds drafts and smarter search.

Can I import from an MLS/IDX feed?

Not in 1.0. Properties are a normal custom post type, so any importer that writes posts can be used; run Settings → Maintenance → Rebuild search index afterwards.

Alerts are not sent.

Alerts run on WP-Cron every hour. If your host disables WP-Cron, add a real cron job that calls wp-cron.php, or click Send alerts now.

Where do agents log in?

On the normal WordPress login; agents are sent to the Agent Dashboard page after logging in.
